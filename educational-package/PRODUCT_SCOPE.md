# Product Scope and Audience

## Product name
Texas CNA Academy Code-Along Educational Repository Package

## Audience
1. **Learners (primary):** self-paced students building practical CNA training workflows.
2. **Instructors (secondary):** educators using structured guides and templates.
3. **Program operators (secondary):** admins managing curriculum operations.

## Tracks
1. **Foundation Track (Beginner)**
   - Repository basics
   - Guided setup and navigation
   - Intro module delivery
2. **Builder Track (Intermediate)**
   - End-to-end code-along module execution
   - Data and template customization
   - Assessment and checkpoint completion
3. **Operator Track (Advanced)**
   - Commercial packaging and release management
   - Access control and entitlement operations
   - Quality reporting and maintenance cadence

## Difficulty levels
- **L1 Beginner:** Follow exact step-by-step instructions.
- **L2 Intermediate:** Complete guided tasks with partial scaffolding.
- **L3 Advanced:** Implement, adapt, and maintain production-ready bundles.

## Learning outcomes
By completion, buyers can:
- Navigate and use a standardized code-along curriculum structure.
- Build modules using templates, sample data, and checkpoints.
- Evaluate outcomes using assessments and completion criteria.
- Operate a commercial learning package with release/version workflow.

## Included assets
- Step-by-step tutorials
- Study guides
- Starter templates
- Sample data files
- Instructor notes
- Assessments and answer keys
- Legal and commercial docs
- Release and feedback workflow docs
