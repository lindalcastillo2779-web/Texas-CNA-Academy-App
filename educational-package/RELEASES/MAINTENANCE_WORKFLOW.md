# Release and Maintenance Workflow

## Versioning
- Use semantic versioning for package docs/assets (`major.minor.patch`).

## Update cadence
- Monthly content quality review
- Quarterly paid bundle refresh

## Workflow
1. Capture learner feedback.
2. Prioritize gaps by completion and assessment outcomes.
3. Update modules/templates.
4. Record changes in changelog.
5. Publish release notes and announce update.
