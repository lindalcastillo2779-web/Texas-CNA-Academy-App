# M01 Foundations: Repository Setup and Guided Navigation

## Learning goals
- Understand package structure and track flow.
- Complete local setup and first guided activity.

## Prerequisites
- Basic command-line familiarity.
- Access to this repository.

## Step sequence
1. Open `START_HERE.md` and `PRODUCT_SCOPE.md`.
2. Review content folders and module template.
3. Run the first guided walkthrough from tutorials.

## Checkpoints
- [ ] Learner can identify free vs paid materials.
- [ ] Learner can locate templates, sample data, and assessments.
- [ ] Learner completes setup verification task.

## Exercises
1. Create a draft module using the starter template.
2. Map a lesson objective to one checkpoint and one assessment item.

## Completion criteria
- [ ] All checkpoints complete
- [ ] Assessment score >= 80%
