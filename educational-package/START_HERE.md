# Start Here: Code-Along Learning Package

## 1) Who this package is for
- Beginner-to-intermediate learners building practical healthcare education tooling.
- Instructors and program leaders who need reusable teaching assets.
- Teams that want structured, step-by-step implementation guides.

## 2) Quick setup
1. Read `./PRODUCT_SCOPE.md`.
2. Review access levels in `./ACCESS_TIERS.md`.
3. Start Module M01 in `./MODULES/M01-foundations.md`.
4. Use templates in `./CONTENT/starter-templates/`.

## 3) Learning progression map
- **Phase A (Free Preview):** Intro tutorial + scope + setup.
- **Phase B (Core Paid):** Module sequence with checkpoints and assessments.
- **Phase C (Advanced Paid):** Production patterns, release workflow, and instructor operations.

## 4) Completion path
- Complete all module checkpoints.
- Pass module assessments.
- Build and submit final project artifacts.

## 5) Need help?
- Support boundaries are defined in `./LEGAL/SUPPORT_SCOPE.md`.
- Feedback process is in `./RELEASES/FEEDBACK_LOG.md`.
